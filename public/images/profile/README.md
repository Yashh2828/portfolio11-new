# Avatar & Profile Images

Use this folder for profile-related images.

## Accepted Formats

- Preferred: `.png`, `.webp`
- Allowed: `.jpg`, `.jpeg`
- Avoid `.svg` for photos

## Required / Recommended Files

| File Name | Purpose | Recommended Size | Max File Size |
|---|---|---:|---:|
| `avatar.png` | Main profile photo | 400 x 400 px | 200 KB |
| `DL.png` | Alternate profile image (optional) | 400 x 400 px | 200 KB |

## Image Rules

- Keep square aspect ratio for avatars
- Use sRGB color profile
- Center face/subject in frame
- Compress before commit (Squoosh, TinyPNG, or ImageOptim)

## Usage Path

- Example reference: `/images/profile/avatar.png`
