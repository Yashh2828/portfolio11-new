# Certification Images

Store certification badges and credential visuals here.

## Accepted Formats

- Preferred: `.png` (transparent background)
- Allowed: `.webp`, `.svg`
- Avoid `.jpg` unless no transparency is needed

## Recommended Specifications

- Aspect ratio: 1:1 (square)
- Recommended size: 200 x 200 px to 300 x 300 px
- Max file size: 120 KB each
- Color profile: sRGB

## Naming Convention

- Lowercase and hyphen-separated
- Suggested pattern: `<provider>-<cert>.png`
- Example: `github-foundations.png`, `mongodb-developer.png`

## Usage Path

- Example reference: `/images/certifications/github.png`

## Tips

- Prefer official provider badge assets.
- Maintain consistent visual sizing across all badges.
- Keep transparent padding balanced for clean card alignment.
