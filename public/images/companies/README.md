# Company Logos

Place company logos for the Experience section here.

## Accepted Formats

- Preferred: `.svg`, `.png` (transparent background)
- Allowed: `.webp`
- Avoid `.jpg` for logos unless transparency is not needed

## Recommended Specifications

- Aspect ratio: square or near-square (1:1 to 4:3)
- Recommended canvas size: 256 x 256 px
- Minimum size: 128 x 128 px
- Max file size: 100 KB per logo
- Color profile: sRGB

## Naming Convention

- Lowercase with hyphens
- Suggested files:
	- `hexaware.png`
	- `upmrc.png`

## Usage in Data

- `/images/companies/hexaware.png`
- `/images/companies/upmrc.png`

## Tips

- Use official brand assets where available.
- Keep padding inside the image balanced so logos look centered in the badge.
- For dark logos, export a version that stays visible on dark backgrounds.
