# Project Images

Store project thumbnails and screenshots for the Projects section here.

## Accepted Formats

- Preferred: `.webp`
- Allowed: `.png`, `.jpg`, `.jpeg`
- Avoid `.svg` for screenshot-style images

## Recommended Specifications

- Aspect ratio: 4:3 (recommended) or 16:10
- Display target: 800 x 600 px minimum
- Hi-res option: 1200 x 900 px
- Max file size per image: 300 KB
- Color profile: sRGB

## Naming Convention

- Use lowercase and hyphens only
- Recommended pattern: `project-<number>.webp`
- Example: `project-1.webp`, `project-2.webp`

## Usage Path

- Example reference: `/images/projects/project-1.webp`

## Tips

1. Keep all cards on one aspect ratio for a clean grid.
2. Export without extra whitespace around screenshots.
3. Use sharp but compressed images to preserve quality and speed.
